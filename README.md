# CSS-VCET Repository

This repository contains various Python programs and assignments organized into different categories.

## 📁 Directory Structure

```
CSS-vcet/
├── prac1/                    # Cryptography Practicals
│   ├── substitution.py      # Substitution cipher implementation
│   ├── transposition.py     # Transposition cipher implementation
│   └── readme.md            # Detailed documentation
│
├── machine-learning/        # Machine Learning Programs
│   ├── linear.py           # Linear regression (Salary prediction)
│   ├── newlinear.py        # Linear regression (Study hours vs Score)
│   └── ai.py               # AI-based Python tools Q&A system
│
├── data-analysis/          # Data Analysis Programs
│   ├── numpaY.py           # NumPy basics (calculating averages)
│   ├── pandastest.py       # Pandas basics
│   ├── matnumpan.py        # Combined NumPy and Pandas operations
│   └── matplotylibtest.py  # Matplotlib visualization basics
│
└── data/                   # Data Files
    ├── analysis.csv        # Tool analysis data for AI program
    ├── salary_data.csv     # Salary dataset for linear regression
    └── studentstudyhours.csv # Study hours dataset for linear regression
```

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- NumPy
- Pandas
- Matplotlib
- scikit-learn (for machine learning programs)

### Installation
```bash
pip install numpy pandas matplotlib scikit-learn
```

## 📚 Usage

### Cryptography (prac1)
Navigate to the `prac1` directory and run the cipher programs:
```bash
cd prac1
python substitution.py
python transposition.py
```

### Machine Learning
Navigate to the `machine-learning` directory:
```bash
cd machine-learning
python linear.py          # Salary prediction
python newlinear.py       # Exam score prediction
python ai.py              # Interactive Python tools Q&A
```

### Data Analysis
Navigate to the `data-analysis` directory:
```bash
cd data-analysis
python numpaY.py          # NumPy examples
python pandastest.py      # Pandas examples
python matnumpan.py       # Combined operations
python matplotylibtest.py # Visualization examples
```

## 📝 Notes
- All CSV data files are located in the `data/` directory
- Python files in `machine-learning/` use relative paths to access data files
- The `prac1/` directory contains detailed documentation in its own README
